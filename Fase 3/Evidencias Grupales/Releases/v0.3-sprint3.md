## Sprint 3: Tres APIs públicas propias

**Período:** 16 al 30 de octubre de 2026

**Fase:** 2

### Objetivo del sprint
Abrir el sistema a otros sistemas con tres APIs propias, documentadas en Swagger y con claves por consumidor.

### Historias terminadas
- HU-15 API de seguimiento de pedidos (RF-OT-12)
- HU-16 API del cotizador referencial (RF-COM-18)
- HU-17 API de disponibilidad de materiales para proveedores (RF-INV-09)

### Incremento entregado
- `/api/publica/v1/` con clave por consumidor, permiso por servicio, límite de 60 consultas por minuto y registro de cada consulta.
- Documentación Swagger en `/api/publica/v1/docs/`.
- Actualización de ERS-01, CU-01, SEC-01, ARQ-01, MOC-01, TEC-01, PPR-01, PRU-01 y EVI-01.

### Calidad
- 55/55 pruebas automatizadas de las APIs y 16/16 casos manuales.
- Regresión: 291/291 pruebas, 93 % de cobertura.

### Ceremonias
